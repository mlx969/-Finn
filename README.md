# 乐天知性（安心答）· GOAI 赛道二参赛项目

分龄性健康教育系统：年龄分流 → 适龄课程 → 权威 RAG 问答 → 安全检测 → 危机转介 → 学习效果评测。
参赛：GOAI 世界人工智能开源大赛 · 赛道二「无界应用（Boundless Agents）」
理念：知识严谨 × 社会学升维 × 适龄分级 × 安全护栏。

---

## 项目定位（一句话讲清「谁 / 学什么 / AI 做什么 / 怎么验证」）

| 维度 | 说明 |
|---|---|
| 学习者是谁 | 分两条线：① 青少版未满 18 岁，做身体权启蒙与健康边界；② 成年版 18+，做性健康与亲密关系科普 |
| 要学会什么 | 身体权与边界、性同意、避孕与防病、危机识别与求助，以及对情感困惑的结构性理解（原生家庭 / 阶层 / 身份） |
| AI 在教学中做什么 | 年龄分流后按适龄课程给要点，用「1 卡 → 情境 → 3 题测验 → 反馈」闭环帮自学；RAG 接权威源做问答；做安全检测与危机转介 |
| 如何验证学会了 | 首页「学习进度」面板实时展示已完成课程和测验平均正确率（本地数据）；「风险识别前后测」是待验证指标，没有规模化实测前不造假 |

> 当前是高保真交互原型：首页课程测验是预设本地样例，但成年版与青少版已接入 Dify 实时 AI 问答（CONFIG.USE_LIVE_DIFY=true）。评测为正则启发式初筛加人工复核，不是裁判模型得分。

## 一、为什么做这个（差异化）

市面上的性教育要么太教科书、要么太猎奇、要么教 PUA。我们做的是一个被忽视的视角：用 AI 把性健康知识、原生家庭与阶层处境的升维理解、安全社群，做成普通人能直接用的东西。

中文开源里心理情感垂类已经很卷（EmoLLM、SoulChat、MeChat 等），但专门做中文性健康教育的开源项目很少。在我检索过的公开样本里，专门做中文性健康教育的极少；国外 5 个相关项目（SafeBubble、TroyHealthLink、sex-education-chatbot-backend、Aarogya_Mitram、SuSastho.AI）都只做生理问答，没有社会学升维、没有社区、没有审核。把升维视角、适龄双版本、安全护栏整合进同一套开源方案，在我检索过的样本里较少见。

> 注：这里的「较少见」是截至 2026-08-15 的公开检索结论，不能证明「全球唯一」或「全球空白」。

## 五、本地运行演示

直接双击 `index.html` 用浏览器打开即可（断网也能跑）：
1. 先过 18+ 年龄门；
2. 青少版：点开任意「身体权启蒙」课程卡 → 看要点 → 做 3 题小测验 → 看「学习进度」面板；
3. 成年版 / 青少版均接入 Dify 实时 AI 问答（CONFIG.USE_LIVE_DIFY=true 时显示对话窗），同时保留预设本地演示问答样例用于断网查看；
4. 扩展内容（成人健康展讯）为独立页 `adult_expo.html`，仅外链官方资源，非参赛教育主线。

> 真实 AI 接入：成年版与青少版已嵌入 Dify 实时对话窗（在 `index.html` 的 CONFIG.adultEmbed / minorEmbed 填入链接、USE_LIVE_DIFY=true 即生效）。Dify Cloud 处理对话时的数据保存策略以 Dify 平台为准。页面无「实时 Key 输入」控件，Key 仅从环境变量读取，绝不写入文件。

### 命令行冒烟测试（验证真模型链路 + 七条安全规则）

```powershell
cd 安心答-GOAI
$env:STEPFUN_API_KEY="你的完整Key"     # 仅环境变量，脚本绝不写入文件
python smoke_test.py                   # 跑 5 条冒烟题，出延迟/得分报告
python smoke_test.py --dry-run         # 不调 API，先验证脚本与规则检测器
```

产出 `smoke_test_report.md` + `smoke_test_result.json`，
报告内 Key 字段恒为 `REDACTED`，可直接截图或随仓库上传。仅需 Python 3，无第三方依赖。

> 演示模式不联网、不收集任何输入数据；真实 API Key 仅从环境变量读取，绝不写入文件或日志。
